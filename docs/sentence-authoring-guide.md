# 가까워 정답 문장 출제 가이드

정답 문장의 출제 기준을 정리한 문서다.

- 1차 작성(2026-06-15): 등록 문장 분석 기반 기준 수립
- 2차 개정(2026-06-15): 명사를 보편 사물 중심으로 조정
- **3차 전면 개정(2026-08-03): 기존 기준을 폐기했다. 운영자가 문장을 하나씩 검수하며 얻은 판정 결과를 규칙으로 다시 세우고 출제 절차도 배치 검수 루프로 바꿨다.**

> 게임 특성: 매일 정답 문장 1개를 출제하고, 플레이어는 추측 문장을 입력한다.
> AI 임베딩 모델(`jhgan/ko-sbert-sts`)이 정답과 추측의 **문장 의미 유사도(%)**를 계산해 피드백한다.

---

## 1. 판정의 기준

좋은 문장인지 가르는 질문은 하나다. **플레이어가 추측을 거듭하면 이 문장에 도달할 수 있는가.**

문장이 자연스러운지는 필요조건일 뿐이다. 멀쩡한 한국어 문장이라도 소재가 조금만 옆길로 새면(눈사람 만들기, 소매 걷기, 함박눈 구경) 플레이어의 연상 경로에서 벗어나 도달할 수 없는 정답이 된다. 길 가는 사람을 붙잡고 "오늘 뭐 했어요?"라고 물었을 때 나올 법한 문장만 살아남는다.

## 2. 형식 규칙

| 항목 | 기준 |
| ---- | ---- |
| 종결 | `-다` 평서형 과거가 기본. 상태를 말할 때는 현재형도 쓴다 (배가 고프다, 날씨가 습하다) |
| 주어 | 1인칭, 생략 |
| 문자 | 순수 한글만. 숫자, 영문, 약어 금지 |
| 길이 | 공백 제외 9~14자 안팎. 어절 수는 세지 않는다 |
| 어휘 | 입말에서 실제로 쓰는 가장 흔한 말. "빗방울이 떨어져서"가 아니라 "비가 와서" |

길이 규칙보다 자연스러움이 먼저다. 글자 수를 맞추려고 말을 비틀지 않는다.

## 3. 통과하는 문장의 꼴

검수에서 살아남은 문장은 대부분 아래 유형에 속한다.

| 유형 | 예 |
| ---- | -- |
| 원인 + 기본 동사 | 배가 고파서 밥을 먹었다 / 목이 말라서 물을 마셨다 |
| 장소-목적형 | 머리를 자르러 미용실에 갔다 / 빵을 사러 빵집에 들렀다 |
| 원인 없는 단문 | 강아지에게 밥을 줬다 / 화장을 하고 나갔다 |
| 경조사 방문 | 친구 돌잔치에 다녀왔다 / 결혼식에 가서 축의금을 냈다 |
| 계절 물품 전환 | 겨울 이불을 꺼냈다 / 전기장판을 켜고 잤다 |
| 가전 청소와 점검 | 세탁기 청소를 했다 / 가스 점검을 받았다 |
| 무언가의 시작 | 영어 공부를 시작했다 / 살이 쪄서 운동을 시작했다 |
| 국민 조합 | 샤워하면서 노래를 불렀다 / 생일이라 미역국을 먹었다 |

두 가지를 특히 지킨다.

- **종결 동사는 그 장면의 가장 기본 동작이어야 한다.** 차렸다, 골랐다, 채웠다처럼 중간 단계에서 끝나면 어려워진다. 밥은 먹고, 옷은 사고, 병원은 간다.
- **목적어는 문장의 나머지가 좁혀 줘야 한다.** 미용실이면 머리가 따라온다. 편의점은 무엇을 사든 이상하지 않아서 우유 같은 목적어에 도달할 수 없다.

## 4. 탈락하는 문장의 꼴

아래 유형은 자연스러워 보여도 검수에서 반복해서 떨어졌다.

| 유형 | 탈락 예 |
| ---- | ------- |
| 색깔 있는 어휘 | 허둥지둥 나갔다, 함박눈이 내려서, 출출해서, 이불을 걷어찼다 |
| 중간 동작이나 미세 동작 종결 | 수저를 놓았다, 소매를 걷었다, 봉투를 묶었다 |
| 순간 반응 장면 | 초인종이 울려서, 신호가 바뀌어서, 벨소리가 울려서 |
| 특정 품목 심부름 | 우유를 사러, 계란이 떨어져서, 건전지를 사러 |
| 명칭이 갈리는 사물 | 드라이어/드라이기, 티비/텔레비전, 밴드/반창고 |
| 심리 장면 | 문을 잠갔는지 확인했다, 늦을까 봐 서둘렀다 |
| 야외 레저 | 등산, 소풍, 수영장, 자전거, 캠핑, 낚시 |
| 신체 밀착 소재 | 때밀기, 콧물, 안약, 핸드크림 |
| 기존 요소 재조합 | 이미 통과한 문장의 명사와 동사를 짜깁기한 문장 |
| 게으름 자조 | 귀찮아서 미뤘다, 씻기 싫어서 그냥 잤다 |

소재 포화도를 관리한다. 한 명사가 이미 서너 번 쓰였으면 그 소재는 접는다. 실제 검수에서도 강아지와 고양이가 다섯 번째쯤 등장하자 바로 끊겼다.

## 5. 출제 절차: 배치 검수 루프

한 번에 수백 문장을 뽑아 올리는 방식은 실패했다. 절반 가까이가 기준 미달이었다. 반드시 아래 루프를 돈다.

1. 후보를 10~20개 단위로 만든다.
2. 운영자가 한 문장씩 O/X 또는 수정안으로 검수한다.
3. 통과분만 출제 데이터에 추가한다.
4. 그 라운드의 탈락 사유를 다음 후보 생성에 반영하며 목표 수량까지 반복한다.

후보를 만들 때마다 기출제 문장(서버에서 이미 사용된 문장)과 확정된 문장 전체를 놓고 중복을 검사한다. 완전 중복은 걸러내고 어절을 여럿 공유하는 유사 쌍은 참고용으로만 보고한다. 틀이 같아도 장면이 다르면(친구 돌잔치에 다녀왔다 / 친구 병문안을 다녀왔다) 정답으로는 서로 구분되므로 함께 둘 수 있다.

## 6. 데이터 관리

출제 데이터는 저장소에 커밋하지 않는다. 날짜별 파일로 만들어 어드민 패널에서 업로드한다. 중복 검사의 기준은 서버에서 내려받은 기출제 목록이다.
