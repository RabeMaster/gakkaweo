# 가까워 정답 문장 출제 가이드

이 문서는 현재 서버에 등록된 정답 문장(`data.csv`, 87문장)을 분석해 정리한 출제 기준이다.
**2026-06-15 개정: 다음 출제부터 난이도를 한 단계 낮춘다.** (배경은 §3 참고)

> 게임 특성: 매일 정답 문장 1개를 출제하고, 플레이어는 추측 문장을 입력한다.
> AI 임베딩 모델(`jhgan/ko-sbert-sts`)이 정답과 추측의 **문장 의미 유사도(%)**를 계산해 피드백한다.
> 글자 일치가 아니라 **의미 유사도**가 핵심이므로, 출제 기준도 "의미가 또렷한 일상 문장"에 맞춰져 있다.

## 1. 현황 요약 (등록된 87문장 통계 - 기존 기준)

| 항목                    | 값                                                                    |
| ----------------------- | --------------------------------------------------------------------- |
| 문장 수                 | 87                                                                    |
| 글자 수(공백 제외)      | 최소 10 / **평균 14** / 최대 20                                       |
| 글자 수(공백 포함)      | 최소 13 / **평균 17.5** / 최대 24                                     |
| 어절 수                 | 최소 3 / **평균 4.6** / 최대 7                                        |
| 어절 수 분포            | 4어절 37개, 5어절 40개 (**4~5어절이 89%**)                            |
| 글자 수(공백 제외) 분포 | 12~15자가 73개 (**84%**)                                              |
| 종결 형태               | **100% `-다` 평서형 과거 시제** (했다 20, 었다 18, 렸다/났다/았다 등) |
| 문장 구조               | 원인·계기·전환의 연결어미를 포함한 짧은 복문 약 72%, 단문 약 28%      |

**한 줄 요약(기존)**: _주어를 생략한 1인칭 화자가, 어제오늘 겪은 일상 한 토막을, 4~5어절 12~15자 단문/짧은 복문으로, `-다` 과거형으로 적은 문장._

이 통계는 **기존 문장의 모습**이다. 신규 출제는 아래 §3 난이도 정책에 따라 이보다 조금 더 쉽게 만든다.

## 2. 핵심 출제 원칙 (6가지)

1. **하나의 일상 장면만 담는다.** 한 문장 = 한 사건. 시간·장소·행동이 그림으로 떠올라야 한다.
2. **누구나 떠올리는 전형적인 장면을 고른다.** 한국인이 "이런 상황이면 보통 이렇게 하지/말하지" 하고 예상할 수 있는 흔한 일상이어야 한다. (난이도의 핵심, §3 참고)
3. **앞↔뒤가 서로를 불러오게 쓴다.** 문장의 앞부분을 알면 뒷부분이, 뒷부분을 알면 앞부분이 유추되도록 인과·목적·공기 관계로 묶는다. (가장 중요, §3.4 참고)
4. **구체적인 명사를 1개 넣되, 대표적인 것으로.** "치킨, 커피, 우산"처럼 누구나 아는 사물이 좋다. 너무 마이너한 디테일("네잎클로버, 룸메이트")은 신규에선 신중히.
5. **1인칭, 주어 생략, `-다` 과거형으로 끝낸다.** "나는"을 쓰지 않고, 동작/감정을 과거로 마무리한다.
6. **짧고 단순하게.** 신규는 단문 중심, 3~4어절·공백 제외 11~14자를 기본값으로 한다.

## 3. 난이도 조정 정책 (이번 개정의 핵심)

### 3.1 왜 낮추는가

플레이어는 한국인이고 한국어 모델로 유사도를 잰다. 정답이 **한국인의 일반적인 연상 흐름과 맞아떨어질수록** 추측을 통해 의미를 좁혀가기 쉽다. 영어권 일상이나 특이한 장면은 한국어 추측과 의미 좌표가 멀어 유사도가 잘 오르지 않는다. 따라서 **한국인이 무난하게 유추할 수 있는 전형적인 장면**을 우선한다.

### 3.2 무엇을 낮추는가 (기존 → 신규)

| 항목       | 기존                                       | 신규(난이도 ↓)                                         |
| ---------- | ------------------------------------------ | ------------------------------------------------------ |
| 전개 방식  | 사고·실수·반전(`-다가 ...잃어버렸다`) 다수 | **전형적 순방향 전개** 위주. 예상 밖 결말 축소         |
| 문장 구조  | 복문 72% / 단문 28%                        | **단문 절반 이상**으로 상향. 사건 1개·부사구 1개       |
| 길이       | 4~5어절, 12~15자                           | **3~4어절, 11~14자**로 살짝 단축                       |
| 핵심 명사  | 마이너한 디테일 포함                       | **대표적이고 친숙한 명사** 우선                        |
| 소재       | 일부 특수 상황 포함                        | **고빈도 일상**(식사·출퇴근·카페·날씨·잠 등) 비중 확대 |
| 앞↔뒤 결합 | 느슨한 경우 있음(시간 부사+임의 행동)      | **앞뒤가 서로를 불러오는** 인과·목적·공기 구조         |

### 3.3 난이도를 낮추는 6가지 레버

1. **전형성을 높인다.** "퇴근하고 한강에서 자전거를 탔다"(전형적) ◎ vs "퍼즐을 맞추다가 조각을 잃어버렸다"(의외) △ → 앞쪽을 택한다.
2. **사고/실수/분실 소재를 줄인다.** 예상 밖 전개는 추측 방향을 흐트러뜨려 어렵다.
3. **단문으로 쓴다.** 사건이 하나면 추측이 한 방향으로 모인다.
4. **핵심 행동을 대표 동사로.** 먹다·가다·사다·보다·타다·마시다처럼 흔한 동사를 중심에 둔다.
5. **소재를 친숙한 영역에서 고른다.** §4의 친숙도 등급 참고.
6. **앞↔뒤를 서로 묶는다.** 앞부분과 뒷부분이 인과·목적·공기 관계여야 부분 정답이 전체로 수렴한다. (§3.4)

> 주의: 너무 낮추지 않는다. `밥을 먹었다`처럼 흔한 한 덩어리만 있으면 한두 번에 끝나 변별력이 사라진다.
> **흔한 장면 + 구체 명사 1개**가 균형점이다. 예: `점심에 김치찌개를 먹었다`, `퇴근길에 편의점에 들렀다`.

### 3.4 앞↔뒤 상호 유추 가능성 (양방향 결합)

유사도 게임에서 플레이어는 추측으로 **부분 의미를 맞히며 전체로 수렴**한다. 따라서 문장의 **앞부분을 알면 뒷부분이 좁혀지고, 뒷부분을 알면 앞부분이 좁혀지는** 구조여야 잘 풀린다. 앞뒤가 따로 놀면 부분 정답이 전체로 이어지지 않아 난이도가 튄다.

**강하게 묶는 3가지 결합 방식:**

| 결합                    | 설명                       | 예시 (앞 ↔ 뒤)                                                                   |
| ----------------------- | -------------------------- | -------------------------------------------------------------------------------- |
| **인과**                | 원인 → 결과                | 더워서 ↔ 아이스커피를 마셨다 / 추워서 ↔ 목도리를 둘렀다 / 졸려서 ↔ 커피를 마셨다 |
| **목적·수단**           | 하려고 → 그 수단           | 환기하려고 ↔ 창문을 열었다 / 머리를 말리려고 ↔ 드라이기를 켰다                   |
| **공기(共起)·스크립트** | 한 행동이 다음 행동을 부름 | 양치를 하고 ↔ 잠자리에 누웠다 / 샤워를 하고 ↔ 머리를 말렸다                      |

**피해야 할 약한 결합:**

- **단순 시간 부사 도입부 + 임의 행동**: `아침에 / 저녁에 / 주말에` 뒤에 아무 행동이나 오면, 앞이 뒤를 제약하지 못한다. (`주말에 부모님께 전화를 드렸다` → "주말에" 다음은 무한대)
  - 보완: 시간 부사를 쓸 거면 **그 시간대의 전형 행동**과 묶는다. (`아침에` ↔ `일어나 세수를 했다`, `밤에` ↔ `불을 끄고 누웠다`)
- **막연한 동반 + 임의 행동**: `~와 함께` 뒤에 아무 행동.

> 자가 점검법: 문장을 절반으로 가린다. **가린 쪽이 자연스럽게 떠오르면** 양방향 결합이 좋은 것이다. 안 떠오르면 앞뒤를 더 강하게 묶는다.

## 4. 문장 구조 규칙

### 4.1 기본 골격

```
[시간/장소 부사구] + [구체 명사 목적어] + [서술어(-다 과거)]
```

예시 해부(신규 톤):

- `점심에 / 김치찌개를 / 먹었다` (시간 + 음식 + 행동)
- `퇴근길에 / 편의점에 / 들렀다` (시간 + 장소 + 행동)
- `주말 아침에 / 늦잠을 / 잤다` (시간 + 대상 + 행동)

### 4.2 단문을 기본으로 (신규)

신규는 **단문을 절반 이상** 출제한다. 복문을 쓸 땐 원인·나열 정도의 자연스러운 연결만 쓰고, 반전·전환(`-다가`)은 아껴 쓴다.

| 연결어미      | 의미           | 신규 사용           | 예시                         |
| ------------- | -------------- | ------------------- | ---------------------------- |
| (단문)        | 사건 1개       | **권장**            | 저녁에 치킨을 시켜 먹었다    |
| `-아서/-어서` | 원인·계기      | 권장                | 비가 와서 집에서 영화를 봤다 |
| `-고`         | 나열·순차      | 권장                | 운동화를 신고 공원을 걸었다  |
| `-다가`       | 도중 전환·사고 | **신중히(난이도↑)** | 축구를 하다가 넘어졌다       |
| `-려고/-느라` | 의도·이유      | 가끔                | 발표 준비하느라 밤을 새웠다  |

### 4.3 종결어미 가이드

- 동작 과거형이 기본: `-했다 / -었다 / -았다 / -갔다 / -왔다 / -탔다 / -봤다 / -샀다 / -마셨다`
- 감정·상태로 끝내도 좋다(소수): `우울하다`, `기분이 좋았다`, `푹 잤다`
- **현재형·미래형·청유형·의문형 금지.** 항상 평서문 종결 `~다`.

## 5. 소재 카테고리 (친숙도 우선, 폭은 넓게)

주제는 조금 넓혀도 되지만, **누구나 무난하게 유추할 수 있는 친숙한 영역**을 우선한다.

### 5.1 친숙도 등급

| 등급                      | 비중      | 영역                                                                                                         |
| ------------------------- | --------- | ------------------------------------------------------------------------------------------------------------ |
| **A. 고친숙 (적극 권장)** | 절반 이상 | 식사/간식, 출퇴근·등하교, 카페·음료, 날씨, 잠·휴식, TV·영화·유튜브, 집안일, 산책, 장보기·쇼핑, 가족과의 일상 |
| **B. 중친숙 (적당히)**    | 일부      | 운동, 가까운 나들이·여행, 병원·약국, 학교 행사, 반려동물                                                     |
| **C. 저친숙 (신중/소수)** | 가끔      | 특이한 취미, 드문 사건·사고, 예상 밖 전환이 필요한 장면                                                      |

### 5.2 기존 등록 분포 (참고)

### 5.3 넓혀도 좋은 새 소재 (친숙 범위 내)

자취 요리, 배달 음식, 카페 공부, 주말 집콕, 명절·가족 모임, 동네 마트, 계절 옷 정리, 휴대폰·게임, 음악 감상 등. **단, 고유명사(브랜드/실명)·전문 용어·시사 소재는 제외.**

## 6. 난이도/수준 기준

가까워는 유사도 게임이라 "정답을 글자로 유추"하는 게 아니라 "의미를 좁혀가는" 난이도다.

- **목표 난이도(신규)**: 한국인이 **몇 번 추측하면 의미가 또렷이 오르는** 수준. 전형적 장면 + 대표 명사 1개.
- **너무 쉬움(지양)**: 흔한 표현 한 덩어리뿐 (예: "밥을 먹었다") → 변별력 없음. 명사 1개로 구체화한다.
- **너무 어려움(지양)**:
  - 예상 밖 전개·사고·반전 → 추측 방향이 흐트러진다.
  - 추상적·관념적 문장(감정/철학) → 의미 좌표가 흐려 유사도가 안 오른다.
  - 두 사건을 욱여넣은 긴 문장 → 임베딩이 평균화돼 변별력이 떨어진다.
  - 마이너한 디테일·고유명사 → 한국어 추측으로 도달하기 어렵다.
- **길이로 조절**: 신규는 11~14자·3~4어절을 기본값으로 약간 쉽게. 16자 이상 복문은 가끔만.

## 7. 금지/주의 사항 (체크리스트)

새 문장이 아래에 하나라도 걸리면 다시 쓴다.

- [ ] 주어 "나는/내가"를 명시하지 않았는가 (생략이 기본)
- [ ] `-다` 평서형 과거로 끝나는가 (현재/의문/청유 금지)
- [ ] **3~4어절, 공백 제외 11~14자** 범위인가 (신규 기준, 그 밖은 재검토)
- [ ] **단문이거나 자연스러운 원인·나열 복문인가** (반전·사고 전개는 아껴 쓰기)
- [ ] **앞↔뒤가 서로를 불러오는가** (앞을 가리면 뒤가, 뒤를 가리면 앞이 떠오르는가 / 단순 시간 부사 도입부 지양, §3.4)
- [ ] 한 문장에 한 사건만 담았는가 (사건 2개 이상 금지)
- [ ] **전형적이고 친숙한 장면인가** (한국인이 무난하게 떠올릴 수 있는가)
- [ ] 대표적인 구체 명사가 1개 있는가 (추상명사만 / 흔한 덩어리만 금지)
- [ ] 실제 고유명사(인명/상호/특정 브랜드)·비속어·시사/정치 소재가 없는가
- [ ] 기존 87문장과 소재·표현이 거의 겹치지 않는가 (변형 재탕 지양)

## 8. 출제 절차

1. **소재 선택**: §5 친숙도 A등급에서 우선 고르고, 최근 출제가 적었던 영역을 배분한다.
2. **장면 구상**: "누구나 겪는 흔한 한 토막"을 전형적 전개로 떠올린다. (사고·반전 지양)
3. **골격 작성**: §4.1 골격(`부사구 + 대표 명사 + -다 과거`)으로 **단문 우선** 작성.
4. **길이 점검**: 3~4어절 / 공백 제외 11~14자인지 확인. 넘으면 수식어를 덜어낸다.
5. **난이도 점검**: 흔한 덩어리만 있지 않은지(명사 1개로 구체화), 의외 전개가 없는지 확인.
6. **체크리스트**: §7 항목을 통과시킨다.
7. **중복 점검**: `data.csv`의 기존 문장과 소재·구문이 겹치지 않는지 확인한다.
8. **등록**: 통과한 문장을 `data.csv`에 한 줄로 추가한다.

## 9. 예시

### 9.1 신규 난이도에 맞는 톤 (전형적·단문·친숙)

```
점심에 김치찌개를 먹었다
퇴근길에 편의점에 들렀다
주말 아침에 늦잠을 잤다
카페에서 아메리카노를 마셨다
저녁에 동네를 산책했다
비가 와서 집에서 영화를 봤다
마트에 가서 장을 봤다
침대에 누워 유튜브를 봤다
```

### 9.2 새로 쓸 때의 템플릿

```
[시간]에 [대표 음식]을 먹었다              → 아침에 토스트를 구워 먹었다
[시간/장소]에 [장소]에 들렀다/갔다          → 퇴근길에 마트에 들렀다
[원인]-서 [흔한 행동]을 했다                → 날씨가 추워서 따뜻한 차를 마셨다
[시간]에 [대표 대상]을 보았다/탔다           → 주말에 가족과 영화를 봤다
```

### 9.3 지양 예시 (왜 안 되는지)

| 문장                                                          | 문제                                                                         |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `행복은 가까이에 있다`                                        | 추상명사, 일상 장면 아님, 유사도 좌표 흐림                                   |
| `밥 먹음`                                                     | 종결어미 위반, 너무 짧고 변별력 없음                                         |
| `퇴근하고 한강에서 자전거를 타다가 친구를 만나 국밥을 먹었다` | 사건 2개 이상, 길이 초과, 난이도 급등                                        |
| `퍼즐을 맞추다가 조각을 잃어버렸다`                           | 예상 밖 전개(사고), 추측 방향 흐트러짐 → 난이도↑                             |
| `주말에 부모님께 전화를 드렸다`                               | 시간 부사 + 임의 행동 → 앞("주말에")이 뒤를 못 좁힘, 양방향 결합 약함 (§3.4) |
| `스타벅스에서 아메리카노를 마셨다`                            | 실제 브랜드 고유명사 (→ "카페에서 아메리카노를 마셨다")                      |
| `오늘 기분이 어땠을까`                                        | 의문형 종결, 과거 평서문 아님                                                |
