# 가까워 정답 문장 출제 가이드

이 문서는 정답 문장의 출제 기준을 정리했다.

- 1차 작성(2026-06-15): 등록 문장(87문장) 분석 기반 기준 수립
- 1차 개정(2026-06-15): 난이도를 한 단계 낮춤
- **2차 개정(2026-06-15): 명사를 "보편 사물" 중심으로 바꾸고, 요리·조리 소재를 덜어내며, 소재를 생활 전반 14개 영역으로 균일하게 배분한다.**

> 게임 특성: 매일 정답 문장 1개를 출제하고, 플레이어는 추측 문장을 입력한다.
> AI 임베딩 모델(`jhgan/ko-sbert-sts`)이 정답과 추측의 **문장 의미 유사도(%)**를 계산해 피드백한다.
> 글자 일치가 아니라 **의미 유사도**가 핵심이므로, 출제 기준도 "의미가 또렷한 일상 문장"에 맞춰져 있다.

---

## 1. 현황 요약 (등록된 87문장 통계 - 참고)

| 항목               | 값                          |
| ------------------ | --------------------------- |
| 문장 수            | 87                          |
| 글자 수(공백 제외) | 최소 10 / 평균 14 / 최대 20 |
| 어절 수            | 최소 3 / 평균 4.6 / 최대 7  |
| 종결 형태          | 100% `-다` 평서형 과거 시제 |

기존 문장은 "치킨, 붕어빵" 같은 **구체적 메뉴**를 자주 썼으나, 실제 출제 과정에서 **담백하고 보편적인 사물**이 더 적합해 신규 출제는 §2~§5 기준을 따른다.

---

## 2. 핵심 출제 원칙 (6가지)

1. **하나의 일상 장면만 담는다.** 한 문장 = 한 사건. 시간·장소·행동이 그림으로 떠올라야 한다.
2. **누구나 떠올리는 전형적인 장면을 고른다.** 한국인이 "이런 상황이면 보통 이렇게 하지" 하고 예상할 수 있는 흔한 일상이어야 한다.
3. **앞↔뒤가 서로를 불러오게 쓴다.** 앞부분을 알면 뒷부분이, 뒷부분을 알면 앞부분이 유추되도록 인과·목적·공기 관계로 묶는다. (§3.4)
4. **명사는 "보편 사물"만 쓴다.** "커피·우산·이불·청소기·버스"처럼 누구나 아는 일상 사물을 쓴다. **특정 메뉴명·식재료·품종·브랜드·작품명·상호는 금지.** (§3.5)
5. **1인칭, 주어 생략, `-다` 과거형으로 끝낸다.** "나는"을 쓰지 않고, 동작/감정을 과거로 마무리한다. 순수 한글만 쓴다(숫자·영문 금지).
6. **짧고 단순하게.** 단문 중심, 3~4어절·공백 제외 11~14자를 기본값으로 한다.

---

## 3. 난이도 및 표현 정책

### 3.1 기본 방향

플레이어는 한국인이고 한국어 모델로 유사도를 잰다. 정답이 **한국인의 일반적인 연상 흐름과 맞아떨어질수록** 추측으로 의미를 좁혀가기 쉽다. 그래서 **담백하고 보편적인 생활 장면**을 먼저 고른다.

### 3.2 출제 규칙 요약

| 항목       | 기준                                                  |
| ---------- | ----------------------------------------------------- |
| 전개 방식  | 전형적 순방향 전개. 사고·실수·반전 지양               |
| 문장 구조  | 단문 중심. 복문은 원인(-아서)·목적(-려고)·나열(-고)만 |
| 길이       | 3~4어절, 공백 제외 11~14자                            |
| 명사       | **보편 사물만** (특정 메뉴·품목·브랜드 금지)          |
| 소재       | 요리·조리 장면 배제, 생활 전반 14개 영역 균일         |
| 앞↔뒤 결합 | 인과·목적·공기로 서로를 불러오게                      |

### 3.3 난이도를 맞추는 레버

1. **전형성을 높인다.** 누구나 떠올리는 흔한 장면을 고른다.
2. **사고/실수/분실 소재를 줄인다.** 예상 밖 전개는 추측 방향을 흐트러뜨린다.
3. **단문으로 쓴다.** 사건이 하나면 추측이 한 방향으로 모인다.
4. **대표 동사를 쓴다.** 켜다·끄다·닦다·갈다·챙기다처럼 흔한 동사.
5. **보편 사물을 쓴다.** §3.5 참고.
6. **앞↔뒤를 묶는다.** §3.4 참고.

### 3.4 앞↔뒤 상호 유추 가능성 (양방향 결합)

플레이어는 추측으로 부분 의미를 맞히며 전체로 수렴한다. **앞부분을 알면 뒷부분이, 뒷부분을 알면 앞부분이 좁혀지는** 구조여야 잘 풀린다.

| 결합              | 설명                       | 예시 (앞 ↔ 뒤)                                    |
| ----------------- | -------------------------- | ------------------------------------------------- |
| **인과**          | 원인 → 결과                | 추워서 ↔ 목도리를 둘렀다 / 졸려서 ↔ 커피를 마셨다 |
| **목적·수단**     | 하려고 → 그 수단           | 머리를 말리려고 ↔ 드라이어를 켰다                 |
| **공기·스크립트** | 한 행동이 다음 행동을 부름 | 양치를 하고 ↔ 잠자리에 누웠다                     |

**피해야 할 약한 결합**: 단순 시간 부사 도입부 + 임의 행동 (`아침에/저녁에/주말에 ~했다`). 앞이 뒤를 제약하지 못한다.

> 자가 점검법: 문장을 절반으로 가린다. **가린 쪽이 자연스럽게 떠오르면** 결합이 좋은 것이다.

### 3.5 보편 사물 vs 특정 품목 (2차 개정 핵심)

명사는 **누구나 아는 보편적인 사물**을 쓰고, **특정 품목/메뉴/브랜드는 쓰지 않는다.** 유사도 게임에서 지나치게 세세한 사물은 한국어 추측으로 도달하기 어렵고, 담백한 일상감도 해친다.

| 구분   | 쓴다 (보편 사물)         | 쓰지 않는다 (특정 품목)              |
| ------ | ------------------------ | ------------------------------------ |
| 음료   | 커피, 차, 물, 주스       | 흑당 버블티, 아메리카노, 카페라테    |
| 음식   | 과일, 빵, 밥             | 김치찌개, 된장찌개, 크루아상, 마카롱 |
| 식재료 | (장·먹을거리 수준)       | 두부와 채소, 시금치, 고등어          |
| 생물   | 강아지, 고양이, 화분, 꽃 | 푸들, 페르시안, 몬스테라, 다육이     |
| 사물   | 우산, 이불, 버스, 휴대폰 | (특정 브랜드/모델명)                 |

**요리·조리 과정도 배제한다.** 끓이기·볶기·썰기·무치기·삶기 등 조리 동작 장면은 만들지 않는다. (단 "차를 끓였다"처럼 보편 음료 준비는 허용)

> 핵심: "졸려서 진한 커피를 마셨다"(보편) ◎ vs "카페에서 흑당 버블티를 주문했다"(특정 메뉴) ✗

## 4. 문장 구조 규칙

### 4.1 기본 골격

```
[부사구(시간/장소/원인)] + [보편 명사 목적어] + [서술어(-다 과거)]
```

예시:

- `추워서 / 목도리를 / 둘렀다` (원인 + 사물 + 행동)
- `청소기를 밀어 / 방을 / 닦았다` (도구 + 대상 + 행동)
- `버스를 기다리며 / 음악을 / 들었다` (상황 + 대상 + 행동)

### 4.2 종결어미

- 동작 과거형이 기본: `-했다 / -었다 / -았다 / -켰다 / -닦았다 / -갈았다 / -챙겼다`
- 감정·상태로 끝내도 좋다(소수): `푹 잤다`, `기분이 좋았다`
- **현재형·미래형·청유형·의문형 금지.** 항상 평서문 종결 `~다`.

## 6. 난이도/수준 기준

- **목표**: 한국인이 몇 번 추측하면 의미가 또렷이 오르는 수준. 전형적 장면 + 보편 사물.
- **너무 쉬움(지양)**: 흔한 한 덩어리뿐 (예: "밥을 먹었다") → 변별력 없음.
- **너무 어려움(지양)**:
  - 예상 밖 전개·사고·반전 → 추측 방향이 흐트러진다.
  - 특정 메뉴·품목·브랜드 → 한국어 추측으로 도달하기 어렵다.
  - 두 사건을 욱여넣은 긴 문장 → 변별력이 떨어진다.
- **길이로 조절**: 11~14자·3~4어절을 기본값으로.

---

## 7. 금지/주의 사항 (체크리스트)

새 문장이 아래에 하나라도 걸리면 다시 쓴다.

- [ ] 주어 "나는/내가"를 명시하지 않았는가 (생략이 기본)
- [ ] `-다` 평서형 과거로 끝나는가 (현재/의문/청유 금지)
- [ ] 순수 한글로만 되어 있는가 (아라비아 숫자·영문·약어 금지)
- [ ] 3~4어절, 공백 제외 11~14자 범위인가
- [ ] 단문이거나 자연스러운 원인·목적·나열 복문인가 (반전·사고 지양)
- [ ] 앞↔뒤가 서로를 불러오는가 (단순 시간 부사 도입부 지양, §3.4)
- [ ] 명사가 **보편 사물**인가 (특정 메뉴·식재료·품종·브랜드·상호 금지, §3.5)
- [ ] **요리·조리 장면이 아닌가** (끓이기·볶기·썰기 등 금지)
- [ ] 한 문장에 한 사건만 담았는가
- [ ] 14개 카테고리에 고르게 분포하는가

## 8. 출제 절차

1. **소재 선택**: §5의 14개 카테고리에서 최근 출제가 적었던 영역을 고른다.
2. **장면 구상**: 그 영역에서 누구나 겪는 흔한 한 토막을 전형적 전개로 떠올린다.
3. **골격 작성**: §4.1 골격(`부사구 + 보편 명사 + -다 과거`)으로 단문 우선 작성.
4. **점검**: 3~4어절·11~14자, 보편 사물, 앞↔뒤 결합, 조리 장면 아님을 확인한다.
5. **체크리스트**: §7 항목을 통과시킨다.
6. **중복 점검**: 기존 등록 문장과 소재·구문이 겹치지 않는지 확인한다.
7. **등록**: 통과한 문장을 출제 데이터에 추가한다.

## 9. 예시

### 9.1 권장 톤 (보편 사물 · 담백 · 강결합)

```
졸려서 진한 커피를 마셨다
추워서 목도리를 꺼내 둘렀다
바람이 차가워서 창문을 닫았다
겨울 한파에 보일러를 틀었다
낮잠을 자려고 커튼을 쳤다
머리를 감고 수건으로 닦았다
이불을 뒤집어 햇볕에 말렸다
버스를 기다리며 음악을 들었다
마트에서 과일을 골라 담았다
헬스장 가려고 가방을 챙겼다
노트북을 켜서 자료를 찾아봤다
기름이 떨어져서 주유소에 들렀다
강아지가 배고파서 밥을 줬다
흙이 말라서 물을 듬뿍 줬다
택배가 와서 상자를 뜯었다
전구가 나가서 새것으로 갈았다
```

### 9.2 지양 예시 (왜 안 되는지)

| 문장                                              | 문제                          |
| ------------------------------------------------- | ----------------------------- |
| `김치찌개를 끓여서 밥이랑 먹었다`                 | 특정 메뉴 + 조리 장면         |
| `카페에서 흑당 버블티를 주문했다`                 | 특정 메뉴명                   |
| `시장에서 두부와 채소를 샀다`                     | 특정 식재료 나열              |
| `주말에 부모님께 전화를 드렸다`                   | 시간 부사 + 임의 행동(약결합) |
| `퇴근하고 한강에서 자전거를 타다가 친구를 만났다` | 사건 2개, 길이 초과           |
| `행복은 가까이에 있다`                            | 추상명사, 일상 장면 아님      |
| `오늘 기분이 어땠을까`                            | 의문형 종결                   |
